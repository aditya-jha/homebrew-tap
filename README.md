# aditya-jha/homebrew-tap

```sh
brew install aditya-jha/tap/onetree
onetree install
```

`Formula/onetree.rb` is updated by a pull request that
[onetree's release workflow](https://github.com/aditya-jha/onetree/blob/main/.github/workflows/release.yml)
opens for each published release; this repo's CI audits, installs and tests it.
